# 🚀 DLL Injector

Welcome to the DLL Injector! ⚡ A simple and versatile tool for injecting DLL files into running processes, such as games and other applications.

## 📖 How to Use

1. **Open the EXE** – Launch the injector executable.
2. **Select Process** – Choose the running game or application you want to target (e.g. CS2).
3. **Select DLL** – Browse your files and select the `.dll` you want to use.
4. **Set Bind** – Configure your preferred keybind, if supported.
5. **Inject** – Press the Inject button to load the selected DLL.
6. **Enjoy!** 🎮

## ✨ Features

- ⚡ Simple and easy-to-use interface
- 🎯 Process selection
- 📂 DLL file selection
- ⌨️ Custom keybind support (if available)
- 🛠️ Useful for testing, modding, and development
